# Spotify Podcast Series: Building My ADE

This folder contains the script collection for a 10-episode audio series based on my blog posts. The goal of this series is to share my learning journey in a lighter, conversational format that is more accessible than full blog posts.

## Series Overview
- **Tone**: Relaxed Indonesian (Indo-English code-switching). Simple, conversational, single-person talk.
- **Duration**: ~6–9 minutes per episode.
- **Content**: Audio-first sharing about my journey building an Agentic Development Environment (ADE).

## Recording Notes
- **Intro/Outro**: E00 acts as the permanent series intro.
- **Consistency**: Keep the conversational style consistent throughout. If you're recording on the go, focus on the "friend-to-friend" vibe.
- **Jargon**: Keep it simple. Avoid reading complex code or logs; describe the *problem* instead.
