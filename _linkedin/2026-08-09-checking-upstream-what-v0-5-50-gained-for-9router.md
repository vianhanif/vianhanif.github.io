# LinkedIn Post (Text-Only, Teaser)

Forking an open-source project feels like isolation at first—until you realize your "custom" features are already being built upstream.

I'd been patching my 9router fork with custom combos and token compression workarounds. When a Headroom upgrade finally forced the issue, I checked upstream — and found it had already shipped proper integration and an embedded dashboard proxy for the same problems.

It's a humbling lesson: maintaining a fork is tax. But it's also how you learn what's stable versus what you've just been patching over.
