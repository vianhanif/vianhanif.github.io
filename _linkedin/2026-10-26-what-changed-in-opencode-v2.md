# LinkedIn Post (Text-Only, Teaser)

Most tech writing about OpenCode V2 leads with a feature list.

Here's the plain-language version: imagine a drive-through where the kitchen tears down after every order vs. your own workshop where the bench still has yesterday's half-finished shelf.

OpenCode V1 was the drive-through. Every command started from zero.

V2 is the workshop. One background server runs. Your session is remembered. Your work is where you left it. And you pick which model provider to point it at — Anthropic, OpenAI, a custom endpoint, a local model, whatever.

That's it. Everything else — agents, permissions, MCP servers, plugins, the web interface, the HTTP API — is elaboration on that one shape.

Most people never need the elaboration. They just want the server to stay open.
