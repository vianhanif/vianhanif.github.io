# LinkedIn Post (Text-Only, Teaser)

Years of writing software. Never once contributed to open source.

That changed when I helped another contributor's MCP Gateway feature become mergeable upstream. Not writing the feature — making it fit: object-vs-string ID mismatches, rebases, waiting.

Right now: 6 open PRs (4 upstream). Zero merged. The gap between working code and mergeable code is where the real lessons live.
